# Research Artifacts

This directory owns research inputs and experimental truth, not product setup documentation.

- [`golden-data/`](golden-data/README.md): active Golden cases, schema, human review, and frozen validation runs.
- [`benchmark/`](benchmark/): benchmark snapshots and local outputs.
- [`design/`](design/): research-runtime and Golden Data design notes.
- [`ideation/`](ideation/): exploratory product ideas and TODOs; not current architecture.

For current product behavior, start at [`docs/README.md`](../docs/README.md). For evaluation methods,
use [`docs/evaluation/README.md`](../docs/evaluation/README.md).
